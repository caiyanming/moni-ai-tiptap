TipTap Chemistry Extension Demo

Interactive demo showcasing chemical formula rendering with KaTeX + mhchem

Features Demonstrated:

  • 🧪 Chemical formulas with mhchem syntax
  • ⚗️ Chemical reaction equations
  • 🌡️ Physical units and measurements
  • ⚡ Input rules for automatic conversion
  • 🎯 Both inline and block chemistry nodes
  • 🛡️ Error handling with graceful fallbacks
  • 📱 Block Stream integration with moniBlockId
