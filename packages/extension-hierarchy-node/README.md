# @tiptap/extension-hierarchy-node

[![Version](https://img.shields.io/npm/v/@tiptap/extension-hierarchy-node.svg?label=version)](https://www.npmjs.com/package/@tiptap/extension-hierarchy-node)
[![Downloads](https://img.shields.io/npm/dm/@tiptap/extension-hierarchy-node.svg)](https://npmcharts.com/compare/@tiptap/extension-hierarchy-node?minimal=true)

The HierarchyNode extension provides native support for hierarchical document structures within TipTap, enabling users to manage and navigate parent-child document relationships directly in the editor.

## Features

- **Native hierarchy block insertion and management**
- **Auto-generation based on child document count**
- **Multiple display modes** (list, grid, cards)
- **Collapsible hierarchy sections**
- **Real-time child document synchronization**
- **Drag and drop support for reorganization**
- **Keyboard shortcuts for quick access**
- **Integration with Moni AI ecosystem**

## Installation

```bash
npm install @tiptap/extension-hierarchy-node
```

## Usage

### Basic Setup

```javascript
import { Editor } from '@tiptap/core'
import { HierarchyNode } from '@tiptap/extension-hierarchy-node'

const editor = new Editor({
  extensions: [
    HierarchyNode.configure({
      autoGenerate: true,
      minChildDocuments: 2,
      autoPosition: 'bottom'
    }),
  ],
})
```

### Commands

The HierarchyNode extension provides several commands:

#### Insert Hierarchy Node

```javascript
// Insert a hierarchy management block
editor.commands.insertHierarchyNode({
  parentDocumentId: 'parent-doc-123',
  childDocuments: ['child-1', 'child-2', 'child-3'],
  position: 'cursor', // 'top' | 'bottom' | 'cursor'
  autoGenerated: false,
  hierarchyType: 'default', // 'default' | 'compact' | 'tree'
  displayMode: 'list' // 'list' | 'grid' | 'cards'
})
```

#### Update Hierarchy Node

```javascript
// Update existing hierarchy node with new child documents
editor.commands.updateHierarchyNode('block-id', ['child-1', 'child-2', 'new-child'])
```

#### Add/Remove Child Documents

```javascript
// Add a child document
editor.commands.addChildDocument('block-id', 'new-child-id')

// Remove a child document
editor.commands.removeChildDocument('block-id', 'child-id-to-remove')
```

#### Sync Child Documents

```javascript
// Trigger synchronization of child documents
editor.commands.syncChildDocuments('parent-doc-id')
```

#### Toggle Collapse State

```javascript
// Toggle hierarchy node collapse/expand
editor.commands.toggleHierarchyCollapse('block-id')
```

#### Set Display Mode

```javascript
// Change display mode
editor.commands.setHierarchyDisplayMode('block-id', 'grid')
```

### Keyboard Shortcuts

- `Ctrl+Shift+H` (or `Cmd+Shift+H` on Mac): Insert hierarchy node

### Events

The extension emits custom events that your application can listen to:

```javascript
// Listen for hierarchy node insertion requests
window.addEventListener('moni:insert-hierarchy-node', (event) => {
  const { editor } = event.detail
  
  // Your logic to get current document's child documents
  const childDocuments = getCurrentDocumentChildren()
  
  editor.commands.insertHierarchyNode({
    parentDocumentId: getCurrentDocumentId(),
    childDocuments: childDocuments.map(doc => doc.id),
    autoGenerated: true
  })
})

// Listen for child document sync requests
window.addEventListener('moni:sync-child-documents', (event) => {
  const { parentDocumentId, editor } = event.detail
  
  // Your logic to fetch and sync child documents
  syncChildDocuments(parentDocumentId).then(childDocs => {
    // Find and update all hierarchy nodes for this parent
    editor.commands.syncChildDocuments(parentDocumentId)
  })
})
```

## Configuration Options

```typescript
interface HierarchyNodeOptions {
  /**
   * HTML attributes for hierarchy nodes
   * @default {}
   */
  HTMLAttributes: Record<string, any>
  
  /**
   * Enable auto-generation based on child document count
   * @default true
   */
  autoGenerate: boolean
  
  /**
   * Minimum child documents required for auto-generation
   * @default 2
   */
  minChildDocuments: number
  
  /**
   * Position for auto-generated hierarchy nodes
   * @default 'bottom'
   */
  autoPosition: 'top' | 'bottom'
}
```

## HTML Attributes

The extension adds several data attributes to hierarchy nodes:

- `data-type="hierarchy-node"` - Node type identifier
- `data-parent-document-id` - Parent document ID
- `data-child-documents` - JSON array of child document IDs
- `data-auto-generated` - Whether the node was auto-generated
- `data-hierarchy-type` - Display type ('default', 'compact', 'tree')
- `data-display-mode` - Display mode ('list', 'grid', 'cards')
- `data-collapsible` - Whether the node can be collapsed
- `data-collapsed` - Current collapse state

### Moni-Specific Attributes

The extension also includes all standard Moni attributes:

- `data-moni-block-id` - Unique block identifier
- `data-moni-parent-id` - Parent block ID
- `data-moni-level` - Hierarchy level
- `data-moni-drag-enabled` - Drag capability
- `data-moni-drag-type` - Drag type ('hierarchy')
- `data-moni-stream-type` - Stream type ('hierarchy')
- `data-moni-stream-mode` - Stream mode ('sync')

## Integration with Upper Layer

When using this extension in the upper layer (e.g., in moni-ai-web), you no longer need the `HierarchyBlockExtension` wrapper. Instead, use the native commands directly:

### Before (with wrapper)

```typescript
// ❌ No longer needed
import { HierarchyBlockExtension } from '@/components/editor/extensions/ai/HierarchyBlockExtension'

const extensions = [
  HierarchyBlockExtension.configure({...})
]
```

### After (native support)

```typescript
// ✅ Use native extension directly
import { HierarchyNode } from '@tiptap/extension-hierarchy-node'

const extensions = [
  HierarchyNode.configure({
    autoGenerate: true,
    minChildDocuments: 2
  })
]
```

### Hook Integration

Update your hooks to use native commands:

```typescript
// useDocumentHierarchy.ts
const autoGenerateHierarchyBlock = useCallback(() => {
  if (!editor || !currentWorkspace || !shouldGenerateHierarchyBlock()) return
  
  const childDocuments = getChildDocuments()
  
  // ✅ Use native command
  editor.commands.insertHierarchyNode({
    parentDocumentId: currentWorkspace._id.id,
    childDocuments: childDocuments.map(doc => doc.id.id),
    position: 'bottom',
    autoGenerated: true
  })
}, [editor, currentWorkspace, shouldGenerateHierarchyBlock, getChildDocuments])
```
